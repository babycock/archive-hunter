# ARCHIVE HUNTER

**Personal Vintage Fashion Discovery Tool**

Archive Hunter is a private Windows desktop application designed to discover and analyze vintage fashion listings across online marketplaces.

The project focuses on finding interesting second-hand and archival fashion pieces from brands such as Stone Island, C.P. Company, Diesel, Prada, Gucci, and other designers.

## Features

- Search vintage fashion listings by brand and keywords
- Filter listings by price, category, and condition
- Identify potentially undervalued items
- Estimate potential resale margins
- Save interesting listings for future reference
- Track searches and listing price changes

## Technology

- Electron
- Node.js
- JavaScript
- HTML & CSS
- PostgreSQL (optional)

## Marketplace Integrations

Archive Hunter is being developed to integrate with officially supported marketplace APIs, including Etsy Open API and eBay Browse API, subject to API access approval.

The application is currently in development. Marketplace API access and live search functionality are not yet fully configured.

## Purpose

This project is intended for personal research and vintage fashion sourcing. It is not a commercial SaaS service.

Archive Hunter is an independent project and is not affiliated with Etsy, eBay, or any fashion brand.
